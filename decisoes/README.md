# Decisões do TCC

Registro das decisões que dão forma ao trabalho. Como o TCC é em dupla, uma decisão só passa a
**aceita** quando os dois autores concordam. Até lá, fica **proposta**.

## Como registrar

1. Copie `template.md` para `NNNN-titulo-curto.md`, usando o próximo número.
2. Preencha contexto, decisão, alternativas e consequências. Escreva o suficiente para quem não
   estava na conversa entender o porquê.
3. Abra com status `proposto` e peça a revisão da dupla. Quando os dois concordarem, mude para
   `aceito` e preencha "Aprovado por".
4. Para mudar uma decisão aceita, não edite o arquivo: crie uma nova decisão e marque a antiga como
   `substituído por NNNN`.
